Coilbook guides

Short, practical guides for people who want to write and run Python on a phone. They're written to be useful on their own, and each one ends with how to do the same thing in Coilbook, an iPhone app that runs Python 3.14 on your device, offline.

  • How to open .ipynb files on an iPhoneWhat an .ipynb file is, three ways to open one on a phone, common problems, and how to run and edit it offline.
