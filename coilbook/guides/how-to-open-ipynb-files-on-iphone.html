How to open and edit .ipynb files on an iPhone

Someone emails you a notebook, a classmate shares one, or you download one from GitHub, and on your phone it's just a file called something.ipynb. Notebooks were made for computers, but you can open and even run them on an iPhone. This guide explains what the file is, your options for opening it, and the problems people run into.

What an .ipynb file is

An .ipynb file is a notebook in the Jupyter format. It's a JSON text file that stores a list of cells: code cells with Python, Markdown cells with headings and notes, and the saved output of the code, such as text, tables and plots. Because it's plain text underneath, any text editor can open it, but you'll see raw JSON rather than a readable notebook.

Three ways to open one on an iPhone

  • View it online. Sites such as GitHub show a notebook as a formatted page in Safari, including the outputs saved in the file. It's good for reading, but you can't run or change anything.
  • Use a cloud notebook service. You upload the file to a hosted service and run it in the browser. It runs on someone else's server, so it needs a connection, usually an account, and your data goes to that server.
  • Use an app that runs notebooks on the phone. The notebook opens locally and runs on your device, so it works offline and your files stay with you.

Reading is not the same as running

Viewing a notebook shows you what its author saw the last time they ran it. Running it executes the code again on your device, and that only works if everything the notebook needs is there: the same packages, and any data files it reads. A notebook that opens data.csv will fail if the file isn't next to it.

Common problems

  • Missing packages. Notebooks often import libraries such as scikit-learn or requests. On a phone you can only use the packages your app includes.
  • Missing data files. Put any CSV or text files in the same folder as the notebook.
  • Cells run out of order. Notebooks keep variables between cells, so running cells in a different order from the one saved can change the results. Use "Run All" or restart the kernel for a clean start.
  • Heavy outputs. A notebook with big embedded images can be slow to open. Clearing the outputs makes the file smaller.
  • Code you don't know. A notebook is a program. Read what it does before you run one from someone you don't know.

Sharing a notebook back

You can send the .ipynb file to a computer unchanged, since it's the same format. Many tools can also export a notebook as a plain .py script, which is handy if you only need the code.

Doing it with Coilbook

Coilbook opens and saves .ipynb files in the Jupyter-compatible format and runs the cells on your iPhone, offline. (Coilbook is an independent app and isn't affiliated with Project Jupyter.)

  1. Get the file onto your iPhone with AirDrop, Mail or the Files app.
  2. Tap the file and choose Coilbook. Or open Coilbook, go to the Files tab, tap +, then Import from Files, and pick the .ipynb.
  3. The notebook opens with its code and Markdown cells and the saved outputs.
  4. Tap the Run All button at the top right to run every cell from top to bottom, tap a cell's run button to run just that cell, or choose Run From Here in its actions menu. The result of a cell's last line appears underneath it. If a cell takes too long, tap Stop.
  5. Tap a cell to edit it. In the ••• menu choose Add Code Cell or Add Text Cell. A cell's actions menu can also convert it between code and text, insert a code or text cell below it, move it up or down, or delete it.
  6. For a clean slate, choose Restart Kernel from the ••• menu, or Clear All Outputs to shrink the file.
  7. To send it on, choose Share Notebook for the .ipynb file, or Share as Python Script for a .py file.

Coilbook includes the Python standard library and numpy for free. pandas tables and matplotlib plots, which appear inline under a cell, are part of Coilbook Pro. There's no pip, so a notebook that imports other packages won't run; you'll see an import error you can read in the console. On the free version, opening or importing a notebook is never blocked, and you can run and edit it. The free limit is 1 notebook in your files, and imported notebooks count toward it (the bundled examples don't): once you have one, creating or duplicating another needs Pro, which makes notebooks unlimited.
