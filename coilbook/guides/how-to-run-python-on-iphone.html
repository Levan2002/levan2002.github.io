How to run Python code on an iPhone

An iPhone doesn't come with Python, but you can still write and run it on one. Whether you want to practice between lessons, test a quick idea or run a script on a train, there are a few ways to do it, and each has trade-offs. This guide explains them, what to look for, and how to run your first script on the phone itself.

Your three options

1. In a web browser

Online editors and cloud notebooks run your code on a remote server and show the result in Safari. There's nothing to install, and they can use big packages. But they need a connection, you're often typing into a small text box, and your code is sent to a server.

2. On a remote machine

If you already have a computer or a cloud server, you can connect to it from your phone with an SSH or remote desktop app and run Python there. It's powerful, but it needs setup and a network, and typing commands into a terminal on a small screen is awkward.

3. With an app that includes Python

Some apps bundle a Python interpreter, so your code runs on the phone itself. These work offline and start quickly. The trade-off is that you get a fixed version of Python and a fixed set of packages, because you can't simply pip install things the way you can on a computer.

What to check before you choose

  • Does it work offline? If you want to code on a plane or in a basement classroom, it has to.
  • Is it real Python? The reference implementation, CPython, behaves the same as it does on a computer. Lookalikes can differ in surprising ways.
  • Which packages are included? Check for numpy, pandas and matplotlib if you do data work, and whether you can add more.
  • Does input() work? Many beginner programs ask the user a question, and not every environment supports it.
  • Can you stop a runaway loop? A program stuck in while True: shouldn't force you to restart the app.
  • Can you get files in and out? Look for support for the Files app, AirDrop and Mail.
  • Is running code free? Some apps put a limit on runs behind a subscription.
  • Where does your code go? If privacy matters, prefer something that keeps code on your device.

Tips for typing code on a phone

  • Beware curly quotes. iOS can swap straight quotes for curly ones in ordinary text fields, and Python can't read curly quotes: you'll get a SyntaxError. A real code editor avoids this. A notes app doesn't.
  • Be consistent with indentation. Python uses indentation to mark blocks, so stick to four spaces per level. A Tab key and a row of bracket, colon and quote keys above the keyboard save a lot of fiddling.
  • Use landscape or an external keyboard for longer code. For short scripts, portrait is fine.
  • Keep programs short. A phone is great for practice, small tools and notebooks. Larger projects are easier on a computer.

Doing it with Coilbook

Coilbook is an app with a real CPython 3.14 interpreter inside. Everything runs on your iPhone, so it works in airplane mode.

  1. Open Coilbook and go to the Files tab. Tap +, then New Script, and give it a name. Names ending in .py run as Python.
  2. Type the script. A row above the keyboard has Tab, brackets, colon, quotes, arrows and Undo, and autocomplete suggests keywords, built-in functions and module members as you type.
  3. Tap Run. The output appears in the console under your code. When the program calls input(), the prompt appears in the console and you type your answer right there.
  4. If a loop won't end, tap Stop. Coilbook halts the program and keeps what it printed so far.
  5. For quick one-liners, open the Console tab. It's an interactive Python console where variables stay around between commands. Try 2 ** 100 or import math.
  6. When you're ready to learn more, the Learn tab has 12 short lessons that check your answers.

Your projects are plain folders that also appear in the Files app under On My iPhone › Coilbook. Coilbook includes the standard library and numpy, and the turtle drawing module. pandas and matplotlib need Pro. There's no pip, so you can't add other packages.
