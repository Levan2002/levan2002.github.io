# what's inside

A whole Python workbench, bound into one app

Everything runs locally on your iPhone, so it's fast to start and works on a plane, a train or a basement classroom.

{}Editor

  • Syntax highlighting and line numbers
  • Extra key row: Tab, brackets, colon, quotes, arrows, undo
  • Autocomplete for keywords, builtins and module members like np.linspace
  • Find and replace

>_Console

  • See print output as it happens
  • Answer input() prompts right inline
  • A Stop button for loops that won't quit
  • An interactive console (REPL) that keeps your variables

[ ]Notebooks

  • Open and save .ipynb files (Jupyter-compatible)
  • Code and Markdown cells
  • Run cell, run all, restart kernel
  • pandas DataFrames as real tables, matplotlib plots inline
  • Export as a .py script

npPackages, built in

The full standard library and numpy, plus pandas and matplotlib with Pro. Everything is bundled, so import just works. There's no pip and nothing to download.

↻Turtle graphics

The standard turtle API draws on a built-in canvas. Spirals, stars and fractals, straight from the code you'd write on a laptop.

12Learn Python

Twelve short lessons that check your answers automatically, plus ready-to-run examples: a rainbow spiral, guess the number, a prime sieve, estimating pi with numpy, the Mandelbrot set, a word counter and a weather-station notebook.

/Your files, your folders

Projects are plain folders that also show up in the Files app under On My iPhone › Coilbook. Open .py and .ipynb files from Files, Mail or AirDrop.

?Explain error  Pro

Stuck on a traceback? Get a plain-language explanation from Apple Intelligence, running on your device. Your code isn't sent anywhere. Needs a device that supports Apple Intelligence.

# faq

Questions, answered

Can I run Python on iPhone or iPad offline?

Yes. Coilbook includes a full CPython 3.14 interpreter that runs on the device itself, so scripts, notebooks, the console and the lessons all work with no internet connection. It's made for iPhone, and iPad can run it as an iPhone app.

Is it real Python?

Yes. It's CPython 3.14, the reference implementation, with the full standard library. Code you write in Coilbook is ordinary Python, so it runs the same way on a Mac or PC.

Does it support pip?

No. Coilbook doesn't download packages from the internet. Instead it ships with the full standard library plus numpy, pandas and matplotlib (and their dependencies: Pillow, contourpy, kiwisolver, fonttools, cycler, pyparsing, python-dateutil, pytz, tzdata, six and packaging), all built in and ready to import. pandas and matplotlib need Pro.

Can I open Jupyter notebooks?

Yes. Coilbook opens and saves .ipynb files in the Jupyter-compatible format, with code and Markdown cells, inline results, pandas tables and matplotlib plots. You can also export a notebook as a .py script. Open notebooks from the Files app, Mail or AirDrop. (Coilbook is an independent app and isn't affiliated with Project Jupyter.)

Does input() work?

Yes. When your program asks for input, the prompt appears in the console and you type the answer right there, just like in a terminal.

What's free, and what does Pro add?

Free: the editor, unlimited code runs, the standard library, numpy, turtle, the console, all lessons and examples, 3 projects and 1 notebook you create. Pro adds pandas and matplotlib, unlimited notebooks and projects, four editor themes and Explain error. Pro is $3.99 a month, $24.99 a year or $49.99 once for lifetime.

Do I need an account? Is my code private?

No account is needed. There are no ads, no analytics and no tracking, and your code and files stay on your iPhone. Details are in the privacy policy.
