Run Python on iPhone

Coilbook runs CPython 3.14 directly on your iPhone. Nothing is sent to a server, so it works the same in airplane mode.

  1. Open the Files tab and create a project, or tap New Script.
  2. Type your code. Here's a classic to start with:
  1. Tap Run. Output appears in the console below your code.

The interactive console

The Console tab is a Python REPL: type a line, get the result right away. Variables stay around between commands, which makes it handy for quick sums, trying out a function or poking at a list.

Using input() on iPhone

Programs that ask questions work the way they do in a terminal. When your code calls input(), the prompt shows up in the console and you type the answer inline, then send it. Your program carries on with what you typed.

Remember that input() always returns text. Wrap it in int() or float() when you need a number.

Notebooks (.ipynb) on iPhone

Coilbook opens and saves .ipynb files in the Jupyter-compatible format, so notebooks move freely between your iPhone and a computer.

  • Cells: add code cells for Python and text cells for Markdown notes.
  • Running: run one cell, use Run All to go top to bottom, or Restart Kernel for a clean slate.
  • Results: the value of a cell's last line appears under it. pandas DataFrames show as real tables and matplotlib plots appear inline.
  • Export: share a notebook as an .ipynb file, or as a plain Python script with Share as Python Script.

To open a notebook someone sent you, tap it in Files, Mail or AirDrop and choose Coilbook. Opening or importing a notebook is never blocked. The free version keeps 1 notebook in your files (imported ones count, the bundled examples don't); Pro makes notebooks unlimited.

Coilbook is an independent app. It reads the Jupyter notebook format but isn't affiliated with Project Jupyter.

pandas & matplotlib on iPhone

With Coilbook Pro, pandas and matplotlib are built in. No installing, no internet. They work best in a notebook, where tables and charts render right under each cell.

numpy is included in the free version. Matplotlib's helpers (Pillow, contourpy, kiwisolver, fonttools, cycler, pyparsing) and pandas' helpers (python-dateutil, pytz, tzdata, six) come bundled too. There's no pip, so packages outside this list can't be added.

Turtle graphics on iPhone and iPad

Coilbook supports the standard turtle module and draws on a built-in canvas, so classroom turtle exercises run unchanged. It's free.

For something more colourful, open the Rainbow spiral example in the Learn tab. Coilbook is an iPhone app; on iPad it runs as an iPhone app, turtle included.

Files and the Files app

Every project is an ordinary folder. Open Apple's Files app and go to On My iPhone › Coilbook to find them: copy, move, zip or share files like any others.

  • Open from anywhere: tap a .py or .ipynb file in Files, Mail or AirDrop and choose Coilbook.
  • Import: in Coilbook's Files tab, use Import from Files to bring in a file.

The free version includes 3 projects; Pro gives you unlimited. Because files live on your iPhone, they're included in your normal device backups and are removed if you delete the app, so keep copies of anything important.

Keyboard row & autocomplete

An extra row above the keyboard puts the characters Python needs one tap away:

Tab ( ) [ ] { } : " ' ← → Undo

As you type, autocomplete suggests keywords, builtins and module members. Type np.lin and np.linspace is waiting. Use Find and Replace to rename a variable across a file. Text size, line numbers and line wrapping can be changed in Settings.

Stop a running program

Accidentally wrote while True:? Tap Stop. Coilbook halts the program and keeps whatever it printed so far, so you can see where it got to. In a notebook, stop the running cell the same way, or use Restart Kernel to clear every variable and start fresh.

Lessons & examples

The Learn tab has 12 short Python lessons. Each ends with a small exercise that Coilbook checks automatically, and you can peek at a solution if you're stuck. The examples are complete programs to run and tinker with: rainbow spiral, guess the number, prime sieve, estimating pi with numpy, the Mandelbrot set, a word counter and a weather-station notebook.

Explain error (Pro)

When a program stops with a traceback, tap Explain to get a plain-language explanation of what went wrong. It uses Apple Intelligence through Apple's on-device Foundation Models, so your code never leaves your iPhone. This feature needs a device that supports Apple Intelligence, with Apple Intelligence turned on.

Restoring purchases

Got a new iPhone or reinstalled Coilbook? Open the Settings tab and tap Restore Purchases. Make sure you're signed in to the App Store with the same Apple Account you used to buy Pro.

  • Lifetime is a one-time purchase and can be shared with your family through Family Sharing.
  • Monthly and yearly subscriptions renew automatically. Manage or cancel them in Settings › Apple Account › Subscriptions on your iPhone.
  • Refunds are handled by Apple at reportaproblem.apple.com.
