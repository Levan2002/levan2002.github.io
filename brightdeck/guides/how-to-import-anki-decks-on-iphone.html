How to import Anki decks on iPhone

By Levani Topchishvili · 6 October 2026

You have spent months building Anki decks on a computer, and now you want to study them on the train with an iPhone or iPad. Brightdeck opens Anki's export files directly, including the pictures, the sounds and, if you want it, your review progress. This guide takes you from the Anki export to your first review on the phone.

What you can import

  • .apkg packages, which hold one deck (or a few) with their media.
  • .colpkg packages, which are a whole collection.
  • Both the current package format and the older one that Anki offers under "support older Anki versions".
  • Packages exported from Anki on a computer, and exports from AnkiMobile or AnkiDroid.

Everything is read on your device. The file is not uploaded anywhere.

Step 1: export the deck from Anki

  1. On the computer, open Anki and choose File, then Export. On a phone version, use the deck's export option instead.
  2. For the export format, pick Anki Deck Package (.apkg) for a single deck, or Anki Collection Package (.colpkg) for everything.
  3. Select the deck you want if you are exporting an .apkg.
  4. Tick Include scheduling information if you want to keep your review progress. Tick Include media if the deck has pictures or sounds.
  5. If you have an unusual or very old setup, you can also tick Support older Anki versions. Brightdeck reads both kinds, so this is a fallback rather than a requirement.
  6. Click Export and note where the file is saved.

The exact wording of the options can vary a little between Anki versions, but the idea is the same: package, scheduling, media.

Step 2: get the file onto your iPhone or iPad

Any ordinary way of moving a file works:

  • AirDrop from a Mac is the quickest.
  • iCloud Drive or another cloud folder that appears in the Files app.
  • Email the file to yourself and open the attachment on the phone.

Keep the .apkg or .colpkg extension. If a service renames it or wraps it in a zip, rename or unzip it so it is a plain package again.

Step 3: open it in Brightdeck

  1. Find the file in the Files app, in Mail or in whatever app received it.
  2. Tap it, then tap the share button and choose Brightdeck, or use Open in Brightdeck if it is offered.
  3. Brightdeck opens and shows the import options.
  4. Or start in Brightdeck: tap + on the Decks screen, choose Import Deck…, then Deck package, and pick the file.

Step 4: decide about your review progress

The import screen has a Keep my review progress toggle. Switch it on if you have been studying this deck in Anki and want Brightdeck to continue from where you left off, with cards you already know scheduled further out. Switch it off if you would rather start the deck fresh, for example when it is a shared deck you downloaded and never studied.

Cards keep their due dates. Brightdeck schedules with FSRS, so it turns each card's interval (or the FSRS memory state Anki already stored) into its own estimate of how well you know the card, and takes over from the next review.

Step 5: check the result

  1. Open the new deck and flip through a handful of cards.
  2. Check that pictures show and that sounds play. You can also set a reading language for the deck and let Brightdeck read cards aloud with the device's voices.
  3. Look at fill-in-the-blank cards. Anki's cloze deletions use the same {{c1::word}} idea that Brightdeck's Fill the blank cards use.
  4. Study a few cards and rate them Again, Hard, Good or Easy as usual.

If something goes wrong

  • The file will not open in Brightdeck. Check the extension is exactly .apkg or .colpkg. Re-export if the file was renamed, truncated or sent through a service that changed it.
  • Pictures or sounds are missing. Re-export with Include media ticked.
  • Everything is due at once. You probably left Keep my review progress off, or exported without scheduling information. Re-export with scheduling ticked and import again.
  • A very large collection is slow. Export one deck at a time as .apkg instead of the whole collection.
  • Still stuck? Email me from the support section of the home page, mentioning which Anki version made the file.

As a last resort, Anki can also export a deck as plain text, and Brightdeck imports CSV and TSV files. You lose media and progress that way, but the card text arrives.

Taking your decks back out

Brightdeck Pro can export a deck as .apkg, keeping your progress, and that file imports back into Anki. So moving over is not a one-way trip. Since version 1.0 has no cloud sync, exporting now and then is also a sensible backup.
