Plain guides for anyone who wants to play Werewolf or Mafia with friends: the rules, how to set up a game for your group size, and how to run the night. Each one is written to be useful on its own, and ends with how to do the same thing in Duskcaller, an iPhone app that acts as the narrator so everyone gets to play.
